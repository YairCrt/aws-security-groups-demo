# aws-security-groups-demo
Uso de Security Groups para validar su funcionamiento con instancias EC2

## ✏️ Descripción
En este laboratorio/proyecto se basa en el uso de SG (Security Groups) y observar su funcionamiento con instancias EC2.
La finalidad es crear dos isntancias EC2, generar SG y observar y validar como los SG controlan el tráfico tanto entrante como saliente.

## 📍 Objetivo
Creación de dos instancias EC2, configuracion de SG y comprobar si las instancias EC2 pueden comunicarse entre ellas usando PING.

** Creación de instancias
- Empecé creando dos instancias accediendo a EC2: 
  * Primera instancia: 
    Tipo: t2.micro
    Sistema: amazon linux
  * Segunda instancia
    Tipo: t2.micro
    Sistema: amazon linux
